# NYC Motor Vehicle Collision Analysis

Individual data analytics project at Masaryk University (2024).

This project analyzed New York City motor vehicle crash records from NYC Open Data, using R for exploratory and temporal analysis, geographic comparisons and regression modelling.

It examines collision counts by location, time, vehicle type and recorded contributing factors. The project report describes logistic regression for accident severity and linear regression for casualties.

The original analysis code has not yet been published. This page provides a research overview rather than a reproducible code release. Counts of crashes are not exposure-adjusted crash rates.
